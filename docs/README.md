# Platform notes

Setup and the published images are in the [repository README](../README.md) and [DEPLOYMENT.md](../DEPLOYMENT.md).

- [Upgrade 1.2.8 to 1.3.0](upgrade/1.2.8-to-1.3.0.md)
- [Upgrade 1.2.9 to 1.3.0](upgrade/1.2.9-to-1.3.0.md)

A finished PostgreSQL 1.2.9 database, or Oracle 23 at 1.2.9, uses the 1.2.9 guide. Oracle before 23 cannot finish 1.2.9, so those databases and any 1.2.8 database use the 1.2.8 guide. A database older than 1.2.8 stops with `upgrade to 1.2.8 first`.
